# gemmie-neocities

Draft of a neocities/Y2K-style personal site, built with Astro.

## Run locally
npm install
npm run dev

## Notes
- Images currently hotlink to the old carrd.co assets as placeholders — swap them for
  self-hosted files in `public/images/` when ready.
- Fonts (Press Start 2P, Quicksand, Caveat) load from Google Fonts via global.css.
- `now playing` widget, profile view counter, and equalizer bars are all static/CSS-driven —
  easy to wire up to a real API later if wanted.
